# 개발 검증 (2026-10-23)

## 수정한 오류

- 개발 서버: public 경로 끝 슬래시 때문에 정상 파일 요청도 403으로 차단하던 문제를 경로 정규화로 수정했다. 임의 포트(PORT=0)도 실제 할당 포트를 로그에 표시한다.
- 입력 초기화: id="reset" 버튼이 form.reset 메서드를 가리므로 기본 HTMLFormElement.reset을 명시적으로 호출한다.
- .gitignore: dist, node_modules, 로컬 환경 변수 파일, 로그와 OS 메타데이터를 제외한다. .env.example은 추적할 수 있다.

## 검증 결과

- npm test: 10개 통과. 서버 회귀 검사는 HTML/CSS/ES 모듈/이미지의 정상 응답, 404, 외부 경로 차단을 실제 HTTP 요청으로 확인한다.
- npm run build: 통과. 사이트 배포는 수행하지 않았다.
- Chromium 1440/768/390 px: 제품 12개 표시, 가로 넘침 없음, 페이지 JavaScript 예외 없음.
- 예산 10만 원 이하+의자 필터(2종), 가격 오름/내림차순, 저장·새로고침 유지·저장 취소·빈 목록 통과.
- 제품 2개 및 3개 비교, 모달 닫기, 4개째 비교 선택 차단 통과.
- 키 입력 반영, 초기화, 외국인 선택 시 국가 입력 표시, 라운지 자동 판정 제외, 추천 기준 모달 통과.
- 기존 디자인/CSS/이미지, IKEA 제품 데이터와 계산식은 변경하지 않았다. 키 기반 계산은 검증 전 예시이며 국가별 임의 보정이 없다.

## 재현

Node.js 20 이상에서 npm test와 npm run build를 실행한다. 별도 터미널에서 npm run dev를 실행한다.
선택적 브라우저 검사는 Python Playwright와 /usr/bin/chromium이 있는 환경에서 python tests/browser-smoke.py로 실행한다. 애플리케이션 자체에는 외부 npm 의존성이 없다. 스크린샷은 출력된 임시 디렉터리에 저장한다. 모바일에서는 하단 추천 기준 버튼을 사용한다(상단 버튼은 기존 반응형 디자인에서 숨겨짐).

브라우저 검사는 주요 기능의 스모크 검사다. 실시간 IKEA 가격·재고나 인체치수 모델의 타당성을 검증하지 않으며, 인쇄 대화상자와 모든 실측 입력 조합에 대한 수동 QA는 포함하지 않는다.
