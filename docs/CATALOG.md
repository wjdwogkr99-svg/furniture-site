# IKEA 한국 제품 카탈로그

현재 스냅샷은 2026-10-23에 확인한 53개 제품이다. 의자 19, 책상 14, 식탁 6, 소파 6, 라운지체어 8종이다. 의자·책상만 업무용 신체 치수와 비교한다. 식탁·소파·라운지체어는 별도 카테고리에서 찾아보고 개별 용도를 확인한다. 높이·좌면 깊이 또는 최근 판매 정보를 확인하지 못한 제품은 자동 추천에서 제외한다. 가격은 마지막 확인일 기준이며 실시간 재고는 제공하지 않는다.

## 수집 범위

5개 공식 카테고리의 공개 HTML 목록(각 24개 카드)과 기존 검토 제품을 읽어, 색상만 다른 변형과 커버·다리 등 부속품을 제외했다. 공개 목록에 나타난 모델에서 한국 상품번호·원화 가격을 확인한 제품만 추가한다. 상세 페이지가 리디렉션되거나 SKU를 검증할 수 없으면 신규 제품으로 추가하지 않는다. IKEA 전체 제품을 가져온 것이 아니며, 현재 수집기는 브라우저의 추가 목록 API를 호출하거나 페이지네이션을 우회하지 않는다. 향후 정식 데이터 제공 경로가 확보되면 같은 형식으로 확장할 수 있다.

제품별 확인일·가격·출처는 docs/products.json과 public/products.mjs, 카테고리별 조회 범위와 제외 기록은 docs/ikea-import-report.json에 있다. 조회 실패 제품을 가짜 수치로 채우지 않는다. 기존 제품 조회 실패 시 마지막 스냅샷을 남기되 판매 정보 재확인 필요로 표시하고 자동 추천에서 제외한다.

## 공식 이미지

53개 모두 해당 한국 판매 구성의 공식 제품 페이지 JSON-LD에서 제품번호를 대조한 뒤 사진 URL을 읽었다. 이미지 서버가 제공하는 ?f=m 크기의 JPEG를 그대로 저장하며, 이미지 생성·수정·임의 도식을 사용하지 않는다. 누락되거나 읽을 수 없는 사진은 사진 확인 필요 안내로 대체한다. 이미지 주소·상품 주소·다운로드 주소·SHA-256은 수집 보고서에 기록한다. npm test는 실제 로컬 이미지 해시를 대조한다. 기존 해외 제품 참고 사진과 임의 도식은 제품 카드에서 제거했으며 hero와 공간 무드 사진은 기존 디자인을 유지했다. 사진 출처 기록이 사용 허락을 의미하지는 않는다.

## 갱신과 검토

Python 3.9 이상, curl, Node.js 20 이상이 필요하다. 프로젝트 루트에서 npm run catalog:refresh를 실행하면 공식 페이지와 사진을 재조회한다. npm test, npm run test:import, npm run build로 검증한다. 임시 다운로드 캐시는 기본 /tmp/fitform-ikea-cache이며 재현/파서 개발에는 python3 scripts/import-ikea.py로 재사용할 수 있다. 동시 요청은 최대 3개이고 각 요청에 지연과 제한 시간을 둔다. TLS 인증 검증을 유지한다.

.github/workflows/catalog-refresh.yml은 매주 월요일 09:00 KST 및 수동 실행에 대한 갱신 워크플로를 정의한다. 원격 기본 브랜치에 병합되고 Actions가 활성화되어야 예약 실행된다. 결과는 14일간 보관되는 ikea-catalog-for-review 아티팩트로 제출하며 원격 코드를 자동 변경·병합하거나 배포하지 않는다. 아티팩트의 제품 데이터·이미지·수집 보고서를 검토한 뒤 별도 커밋으로 반영한다. 이 작업에서 원격 예약 실행이나 자동 가격 갱신이 이미 활성화된 것은 아니다.
