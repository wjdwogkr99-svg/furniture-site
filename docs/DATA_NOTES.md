## 근거 링크

각 제품의 정확한 한국 상품 URL, 제품번호, 색상/구성, 확인일은 `products.json`과 `../public/products.mjs`에 기록했다. 가격이나 치수를 갱신할 때 해당 URL의 치수표와 제품 본문을 함께 확인한다. TROTTEN처럼 사양이 상충하면 보수적으로 미확인 처리한다. 예전 EKENÄSET 705.334.91 주소는 제품 카테고리로 리디렉션되어 현행 106.243.33을 사용했다.

## 사진 출처

`products.mjs`의 `imageSource`가 각 참고 제품 이미지의 출처다. 같은 모델이어도 국가별 사진은 쿠션·발·색상·구성이 다를 수 있으므로 한국 치수 근거로 쓰지 않는다. 9개 제품은 실제 공식 IKEA 이미지, 나머지 3개는 실제 제품 이미지가 아니라는 설명을 붙인 도식이다. 기존 hero와 업무 공간 사진은 Humanscale 공간 무드 이미지로 유지했다. 자료의 출처 표시는 사용 허락을 의미하지 않으므로 공개 서비스 전 사용 조건을 확인한다.

## 사람 치수 계산

- 키 기반 비율은 UI 시제품용 미검증 설정이며 통계 자료나 브랜드의 공식 산식이 아니다.
- 실측값 우선 계산의 여유값도 검토용 설정이다.
- 국적·성별·연령별 비율 보정은 없다. 나이는 성인 입력 범위 확인에 사용한다.
- 라운지체어는 업무용 착석 모델로 자동 판정하지 않는다.
- 치수 범위의 일부 겹침만으로 제품 전체 적합성을 보장하지 않는다.
